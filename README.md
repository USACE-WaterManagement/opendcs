# Purpose
This repository contains a USACE specific fork of OpenDCS to allow for operational complexities.
Changes will lag behind the upstream http://github.com/opendcs/opendcs main branch and be updated as
desired by USACE Water Management staff.

We will likely make releases, and you're welcome to use them. However, no support will be provided. If you are 
a general user of OpenDCS you should prefer releases from the Upstream project.


# Future

Additionally, OpenDCS has plans to better "disconnect" the extra implementations from the core code. It is desired
that this repository will eventually just come the "cwms-implementation" source and not a full fork for OpenDCS.
